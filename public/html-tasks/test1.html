4. Computer & Web Glossary

Every student must master the following foundational definitions:

HTML (HyperText Markup Language)
The standard markup language used to structure web pages and their content using tags and attributes.
URL (Uniform Resource Locator)
The global address used to locate resources and web documents on the Internet.
Hyperlink
An active HTML reference element that allows users to navigate instantly from one webpage to another by clicking text or images.
Browser
A software program (such as Google Chrome, Firefox, or Edge) that retrieves, renders, and displays HTML documents to end users.
