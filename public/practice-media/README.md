# Practice media

These two SVG illustrations and the six-second shapes video were created for
Knobly's HTML practice compiler. They contain no user data or external assets.
You may copy, modify and reuse them in learning projects.

`shapes.mp4` is a silent H.264 / yuv420p video, 640 × 360, generated from solid
colours and moving rectangles. It does not autoplay in the media picker.
